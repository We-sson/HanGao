# 通用机器人配置教学图

本目录图片用于解释配置字段和获取参数的方法，由项目已有的装配坐标、六轴父子运动链与位姿约定绘制。它们是概念教学示意，不代表任何特定型号的外形、尺寸、行程或校准结果；图片中没有厂家型号数值，也没有依赖外部 PDF 或 Downloads 路径。

| 图片 | 教学内容 |
| --- | --- |
| `model-assembly.png` | Base 与 J1～J6 拆分为独立 STEP，但保留同一个 CAD 装配全局原点和方向；运动链按 Base → J1 → … → J6 连接。图中的折线只表达父子关系，不规定实际轴线的相交、共轴或腕部结构。 |
| `joint-axis.png` | 通过相邻部件的配合圆柱面或旋转中心线确定轴线；取线上一点 P1 作为轴心，两点差 P2−P1 作为非零方向。最终方向符号应按右手规则与对应控制器的正转约定核对，不能直接采用圆柱面的参数方向。 |
| `angle-reference.png` | 行程来自对应型号手册或控制器；CAD 参考角是导出姿态对应的关节角，启动角是项目选择的初始姿态；模型实际转角为当前角度减去参考角。STEP 几何本身不记录机器人编码器角度。 |
| `flange-frame.png` | 法兰中心通常取末轴旋转轴线与安装基准面的交点；XYZ 使用原始 CAD 装配全局坐标，ABC 使用项目约定 Rz(A)·Ry(B)·Rx(C)。法兰局部 X/Y 的绕轴基准应从定位基准或控制器坐标确认，不能仅凭安装平面和轴线确定。工具 TCP 相对于法兰单独配置。 |

实际参数应以相应机器人的厂家资料、CAD 装配测量和控制器姿态记录为准。文件与数值校验不能代替机械校准或真实正转方向确认。

再生成脚本保留在本聊天的可视化工作目录 `generic-setup-guide/generate.py`，不会参与应用运行；图片作为 Debug 配置向导资源使用。
