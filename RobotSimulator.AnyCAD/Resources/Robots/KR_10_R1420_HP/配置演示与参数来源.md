# KR 10 R1420 HP 配置演示与参数来源

此目录的 `KR_10_R1420_HP.robot.json` 是仿真演示配置。关节行程来自对应型号资料，轴线和法兰中心来自本目录 STEP 实测。**参考角、轴正方向及法兰绕自身轴的朝向是演示约定，待实际控制器核对。** STEP 导出时没有保存示教器六轴角度；用户已同意按演示姿态建立映射。

## 页面操作

1. Debug 启动仿真，点击“新机器人配置向导（开发）”。
2. 选择本目录。首次新建时只需七份 STEP；本演示保存后再次打开会载入现有参数。`Base.STEP` 对应基座，`J1.STEP`～`J6.STEP` 对应六轴。
3. 在“六轴关节参数”中依次选择 J1～J6，按下表填写。XYZ 为 CAD 装配全局坐标，单位 mm；角度单位为度。
4. 在“法兰坐标参数”填写中心 `(890, 0, 1080)` 和演示 ABC `(0, 90, 0)`。
5. 进入“校验与保存”，保存同目录的机器人 JSON。重新构建后，在主界面选择 `KUKA KR 10 R1420 HP`。
6. 先保持启动姿态，再逐轴小幅增加角度，核对轴心、下游零件随动和方向。最后核对法兰及 Tool 安装。文件与数值校验不代表真实机器人已经标定。

## 每项数据如何取得

**行程**：用户提供的 `0000258988_ZH.pdf`，共一页，型号 KR 10 R1420 HP，文档号 0000-258-988，V11.1，2022-07-08。左下“轴数据 → 运动范围”直接列出 A1～A6；A 对应这里的 J。不使用另一型号的行程，也不把轴速度填入角度行程。

**轴线上一点和轴线方向**：在 CAD 装配中找相邻关节配合的圆柱面或旋转中心线，用测量工具读取轴线上一点的全局坐标。此次直接读取 STEP 的 `CYLINDRICAL_SURFACE → AXIS2_PLACEMENT_3D → CARTESIAN_POINT / DIRECTION`，并比较相邻两个零件，确认是同一条配合轴线。七份文件的单位均为 mm。

| 关节 | 本模型可复核的几何证据（STEP 实体编号） |
| --- | --- |
| J1 | Base `#17871/#45402` 与 J1 `#26324/#49787`：半径 50 的圆柱，轴线 x=y=0，取其点 z=237。 |
| J2 | J1 `#9344/#11871` 与 J2 `#16760/#20678` 等圆柱同轴，x=150、z=450，沿 Y。 |
| J3 | J2 `#3997/#24102` 与 J3 `#5051/#7799` 等圆柱同轴，x=150、z=1060，沿 Y。 |
| J4 | J3 `#25468/#25617` 与 J4 `#7359/#23016` 的半径 45 圆柱同轴，y=0、z=1080，沿 X。 |
| J5 | J4 `#14092/#16985` 与 J5 `#1400/#1563` 等半径 29 圆柱同轴，x=810、z=1080，沿 Y。 |
| J6 | J5 `#71/#686` 与 J6 `#53/#223/#435/#736` 的圆柱同轴，y=0、z=1080，沿 X。 |

旋转轴心只需是轴线上的一个点，并非必须选某个唯一点。J4 和 J6 的轴心取腕心 `(810,0,1080)`；沿该 X 轴换一个点，旋转效果相同。J4/J6 在此姿态同轴，J5 与它们相交，所以三者可使用同一腕心，方向不同。

**与资料尺寸交叉核对**：“工作空间图”可核对 A1/A2 水平偏置 150、A2 高度 450、上臂中心距 `1060−450=610`、腕部高差 `1080−1060=20`、前臂长度 `810−150=660`、腕心至法兰面 `890−810=80 mm`。1420 是最大工作半径，不能填成当前姿态的法兰 X。资料图中其他空间包络尺寸也不能直接作为 CAD 原点偏移。

**轴正方向**：圆柱轴线只能确定几何方向，不能确定示教器角度增加时的正负。本演示约定 J1 为 −Z、J2/J3/J5 为 +Y、J4/J6 为 −X，并按右手规则转动。真实接入时应与控制器正转箭头或小角度示教比较，反向则将向量 XYZ 同时取反。这些符号没有被本单页资料确认。

**CAD 参考角与启动角**：STEP 中上臂竖直、前臂水平；文件没有编码器角度。本演示将该姿态映射为 `(0,-90,90,0,0,0)`，并令启动角等于参考角，使 `模型转角 = 当前角度 − 参考角 = 0`，启动时保持导出姿态。换用其他启动姿态只调整启动角；真实示教器映射需在获得原始角度后更新参考角。

**法兰中心**：J6 的安装平面 `PLANE #203` 位于 x=890；安装面圆边 `CIRCLE #23/#735` 的中心为 `(890,0,1080)`。它是安装平面与 J6 轴线的交点。应读取安装面，不能把工具 TCP 或法兰厚度另一面的中心混入。

**法兰 ABC**：法兰朝外为全局 +X；仅有圆柱和安装面仍不能唯一确定法兰 X/Y 的绕轴角。本演示约定法兰 `X=−全局Z、Y=全局Y、Z=全局X`，按项目 `R=Rz(A)·Ry(B)·Rx(C)` 得到 `(0,90,0)`。这组角度描述演示安装坐标，需结合定位孔/Xm 基准或控制器法兰坐标核对，不能声称直接来自资料表。
