# IRB2600-20/1.65：从哪里开始配置

本目录已提供 `IRB2600_20_165.robot.json`，重新构建后可在机器人列表中选择 `ABB IRB 2600-20/1.65`。向导选择本目录时也会载入这份配置。行程来自用户提供的 ABB 数据表，轴线和法兰中心来自七份 STEP；零位、正转方向和法兰朝向采用下文的仿真参考映射，尚未由实际控制器确认。

## 1. 先对应文件，不填角度和坐标

在开发配置向导里选择本目录，基座选择 `Base.STEP`，依次对应 `J1.STEP`～`J6.STEP`。源文件头分别写有 ABB 的 `BASE`、`LINK1`～`LINK6`，与此顺序一致。七份文件单位都是 mm，使用同一套全局坐标，不能逐个重新居中。

## 2. 从手册抄行程

资料为用户提供的 `IRB2600-Datasheet_CN_Rev.C.pdf`，中文版 2019 年 6 月。第 2 页右上角“运动”表给出以下工作范围：

| 配置关节 | 手册轴号 | 最小角度（°） | 最大角度（°） |
| --- | --- | ---: | ---: |
| J1 | 轴1旋转 | -180 | 180 |
| J2 | 轴2手臂 | -95 | 155 |
| J3 | 轴3手臂 | -180 | 75 |
| J4 | 轴4旋转 | -400 | 400 |
| J5 | 轴5弯曲 | -120 | 120 |
| J6 | 轴6翻转 | -400 | 400 |

旁边的 °/s 是速度，不填入角度行程。轴4/轴6额外写的“最大转数 ±251”也不是 ±251°，不能替代本表的工作范围；实际使用范围还应与该台控制器配置核对。

## 3. 从 J1 开始，每次只量一个连接处

在 CAD 中打开原始整机装配，保留全局坐标。只显示当前轴与上一级两个零件，找轴承或配合圆柱的共同中心轴。选一条完整圆边读取圆心，或在中心轴上建立一点，再读取该点的全局 XYZ。

以下是直接从当前 STEP 圆柱轴线取得的记录。坐标仅对应这份原始装配；方向列只确认几何轴线，不包含控制器正转符号。

| 当前轴 | 查看哪两个零件 | 轴线上可用的一点 XYZ（mm） | 几何轴线 |
| --- | --- | --- | --- |
| J1 | Base 与 J1 | (0, 0, 445) | 沿 Z |
| J2 | J1 与 J2 | (150, 0, 445) | 沿 Y |
| J3 | J2 与 J3 | (150, 0, 1145) | 沿 Y |
| J4 | J3 与 J4 | (437.5, 0, 1260) | 沿 X |
| J5 | J4 与 J5 | (945, 0, 1260) | 沿 Y |
| J6 | J5 与 J6 | (1030, 0, 1260) | 沿 X |

### 以 J2 完整说明一次

1. 只看 `J1.STEP` 与 `J2.STEP` 的肩部连接。
2. 在 `J2.STEP` 中，圆柱面 `#16400/#22300` 的中心轴经过 `(150, -140.4, 445)`，沿 Y。`J1.STEP` 对应圆柱面 `#12566/#18041` 也位于同一根轴线上。
3. 把轴心填成 `(150, -140.4, 445)` 可以；沿 Y 轴平移后整理为 `(150, 0, 445)` 也可以，旋转效果相同。轴心参数描述的是一根旋转直线，不是必须选某个唯一的球心。
4. 根据该型号的正转定义选择 +Y 或 −Y。+Y 的向量是 `(0,1,0)`，−Y 是 `(0,-1,0)`；不能仅根据 STEP 圆柱的内部方向选正负。
5. 把手册行程填成最小 `-95`、最大 `155`。
6. 按导出姿态记录填写“模型导出时的关节角”。只有确认这是该轴厂家 0° 姿态时才填 `0`；点“启动保持导出姿态”，让启动角等于导出角。
7. 点击“检查 J2，再配置 J3”。文件、行程、轴线数值通过后才切到下一轴；运动方向需要保存并构建后再小幅转动核对。

其他轴重复同样的动作。不要先尝试猜齐六轴数值，再一次性保存。

## 4. 六轴填完再量法兰

在 `J6.STEP` 上找到真正安装 Tool 的端面。安装平面 `#766` 位于 X=1030，与 J6 轴线相交于 `(1030,0,1260)`；安装面圆边 `#1569/#1732` 的圆心也在此处，半径约 31.5 mm。因此法兰 XYZ 可以填写 `(1030,0,1260)`。

法兰 ABC 不能只靠这个平面得出：还要按 ABB 的接口定位基准或控制器法兰坐标，确定法兰 X/Y/Z 的朝向，再按本项目的 `Rz(A)·Ry(B)·Rx(C)` 换算。数据表的工作空间包络尺寸不是法兰安装坐标，也没有给出这份 STEP 的关节零位记录。

## 5. 最后保存、构建、逐轴核对

保存源配置，重新构建 Debug，再选择该型号。每次只把一个轴增加几度，确认转动轴线、方向和所有下游零件一起运动。偏心查轴线，反向查方向符号，固定角度偏差查导出角映射。与实机对应前还需要用控制器核对角度映射、正转符号及法兰基准。

## 6. 配置文件采用的仿真参考映射

当前 STEP 中上臂竖直、前臂向全局 +X 伸出。参考 [ROS-Industrial IRB2600 模型](https://github.com/ros-industrial/abb/blob/noetic-devel/abb_irb2600_support/urdf/irb2600_12_165_macro.xacro)建立名义零位映射。该项目的[型号说明](https://github.com/ros-industrial/abb/blob/noetic-devel/abb_irb2600_support/README.md)明确覆盖 1.65 m 的 12 kg 和 20 kg 版本；它是社区维护的仿真模型，不是本台机器人的标定记录。

| 关节 | 启动角 = 模型参考角（°） | 配置正方向 XYZ |
| --- | ---: | --- |
| J1 | 0 | (0, 0, 1) |
| J2 | 0 | (0, 1, 0) |
| J3 | 0 | (0, 1, 0) |
| J4 | 0 | (1, 0, 0) |
| J5 | 0 | (0, 1, 0) |
| J6 | 0 | (1, 0, 0) |

这些零值是本次建立的名义姿态映射，不是 STEP 中保存的编码器读数，也不是因为模型原点在 `(0,0,0)`。启动角等于模型参考角，因此启动时六轴实际模型转角均为 0，保持当前装配姿态。

ROS 模型使用相邻关节的局部位移；沿零位运动链累加后，肩部 `(150,0,445)`、肘部 `(150,0,1145)`、腕心 `(945,0,1260)` 和法兰 `(1030,0,1260)` 与本目录实测一致。其 J4 轴点为 `(150,0,1260)`，本配置取 `(437.5,0,1260)`，两点同在沿 X 的旋转直线上，效果相同。

法兰中心采用实测 `(1030,0,1260)`。朝向参考该模型的 `tool0`：`X=-全局Z、Y=全局Y、Z=全局X`，换算为本项目 ABC 是 `(0,90,0)`。这里使用项目规定的 XYZ/ABC 表达，不是 ABB RAPID 四元数；此朝向仍需结合本台法兰定位基准核对。

**行程没有照抄 ROS 模型。** 其 J2/J3 下限等数值与用户提供的数据表不同，本配置统一使用第 2 节的 ABB 表格。社区模型的方向也仅作为仿真参考，未证明该方向与本台控制器及这组行程完全对应。

已确认：七份模型的 mm 单位、六组相邻零件的同轴关系、法兰安装面与圆心、数据表行程。待控制器确认：导出姿态的六轴读数、六轴正转符号、法兰 X/Y 零扭转基准。当前文件可以加载和演示，不代表完成实机校准。
