# KR 20 R1810-2 配置与参数来源

本目录包含七份 STEP 和同目录名的 `KR_20_R1810_2.robot.json`。重新构建后，顶部机器人列表会出现 `KUKA KR 20 R1810-2`；开发配置向导选择本目录可载入现有参数。

## 数据来源

行程来自用户提供的 `0000321012_EN.pdf`，文档号 `0000-321-012`，版本 V15.1，日期 2025-09-27，共一页。使用左侧 `Axis data → Motion range`，不使用下方的速度表。轴线和法兰中心来自当前 STEP，并与右侧工作空间图交叉核对。

| 关节 | 最小 / 最大角度（°） | 启动角 = 模型参考角（°） | 全局轴线上一点 XYZ（mm） | 仿真正方向 XYZ |
| --- | --- | ---: | --- | --- |
| J1 | -185 / 185 | 0 | (0, 0, 280) | (0, 0, -1) |
| J2 | -185 / 65 | -90 | (160, 0, 520) | (0, 1, 0) |
| J3 | -138 / 175 | 90 | (160, 0, 1300) | (0, 1, 0) |

当前型号 A5 的行程是 ±130°。只应用本型号的数据，不把其他机器人的行程复制过来，也不据此改写其他型号配置。

## STEP 几何与装配变换

七份文件均为 mm。Base、J1～J4 中的装配变换为单位变换。**J5 与 J6 包含约 +205 mm 的 X 向装配平移，测量时需要使用变换后的整机坐标。**

| 轴线 | 可复核的 STEP 几何 |
| --- | --- |
| J1 | Base 圆柱 `#2824/#9123`、J1 圆柱 `#38347/#54521` 均沿 x=y=0 的 Z 轴；选取 J1 的 z=280 点。 |
| J2 | J1 圆柱 `#14837/#25630` 与 J2 `#33035/#37716` 同轴，x=160、z=520，沿 Y。 |
| J3 | J2 圆柱 `#21086/#38664` 与 J3 `#1990/#31776` 同轴，x=160、z=1300，沿 Y。 |
| J4 | J3 圆柱 `#43991/#75065` 与 J4 `#4042/#5843` 均沿 y=0、z=1450 的 X 轴。 |
| J5 | J4 圆柱 `#3380/#4205` 的轴线 x=1020、z=1450；J5 `#3702/#5437` 的局部 x≈815，加装配平移后为 1020。 |
| J6 | J5 圆柱 `#7685/#8404` 与 J6 `#6/#219` 均沿 y=0、z=1450 的 X 轴；X 向平移不改变该轴线。 |

J5 的 `ITEM_DEFINED_TRANSFORMATION #8335`、J6 的 `#1023` 引用装配坐标点 `(204.999996933,0,0)`。例如 J6 安装平面 `PLANE #542` 的局部 X≈968，加装配平移后为 X=1173；不能把局部的 968 直接填为法兰全局 X，也不能再次把 STEP 文件整体手动移动 205 mm。

J4/J6 在当前姿态同轴，J5 与它们相交，所以三轴均选腕心 `(1020,0,1450)` 作为轴上一点；三轴的方向不同。轴心点可以沿同一根旋转直线移动，不要求唯一。

## 与资料图核对尺寸

- 肩部水平偏置 160 mm，肩部高度 520 mm。
- 上臂中心距 780 mm，因此肘部高度 `520+780=1300`。
- 前臂与肘部高差 150 mm，因此腕心高度 `1300+150=1450`。
- 前臂长度 860 mm，因此腕心 X=`160+860=1020`。
- 腕心至法兰面 153 mm，因此法兰 X=`1020+153=1173`。

法兰中心为 `(1173,0,1450)`。工作空间图上的 1813 mm 是最大工作半径，不是当前装配姿态的法兰 X。法兰图的 Ø63、Ø31.5、Ø50 孔分布用于核对接口，不能代替全局安装坐标。

## 角度映射与法兰朝向

当前 STEP 为上臂竖直、前臂水平姿态。本次沿用项目 KUKA 仿真约定，将它映射为 `(0,-90,90,0,0,0)`；启动角等于模型参考角，因此模型实际转角均为 0，启动时保持导出装配。该映射不是 STEP 中记录的编码器角度，仍待真实控制器核对。

正方向采用 J1=-Z、J2/J3/J5=+Y、J4/J6=-X 的仿真映射。单页资料没有确认这份导出模型与示教器正转的对应关系；若实机方向相反，应整体取反对应方向向量。

法兰采用 `X=-全局Z、Y=全局Y、Z=全局X`，按项目 `Rz(A)·Ry(B)·Rx(C)` 得 ABC=`(0,90,0)`，使 Tool 朝法兰外侧的 +X 方向安装。法兰 X/Y 绕自身轴的基准同样需要与定位基准或控制器核对。本文件可用于仿真加载，不代表已经完成实机标定。
